Mercado Livre — como pegar Cookie e x-csrf-token (F12)

O Hub afiliados/hub só funciona logado. O painel usa a mesma sessão do Chrome: Cookie + x-csrf-token + etiqueta. Quando o Sync Hub ou as Listas ML falharem, o Cookie expirou — repita estes passos.

Passo a passo (Chrome / Edge)

  1. Abra o Hub de afiliados já logado na conta Careca VIP.
  2. Pressione F12 (ou Ctrl+Shift+I / no Mac Cmd+Option+I).
  3. Vá na aba Rede (Network). Deixe marcado “Preservar log” / Preserve log se existir.
  4. No filtro da Rede, digite: createLink (ou createUrls / afiliados).
  5. No Hub, clique em Compartilhar em qualquer produto (para gerar um meli.la). Isso dispara a requisição.
  6. Na lista da Rede, clique na requisição createLink (ou similar).
  7. Painel direito → Cabeçalhos / Headers → seção Cabeçalhos da solicitação / Request Headers:
    • Copie o valor de x-csrf-token → cole no campo x-csrf-token abaixo.
    • Copie o valor inteiro de Cookie (é longo) → cole no campo Cookie.
  8. A etiqueta (tag) aparece no corpo (Payload / Request) em JSON, tipo "tag":"carecavip", ou em Administrar etiquetas no Hub.
  9. Clique em Salvar sessão Hub e depois em Testar sessão. Se ok → Importação → Sync Hub.

Onde olhar no F12

Rede → createLink → Cabeçalhos ├─ Request Headers │ ├─ cookie: ssid=…; _d2id=…; … ← cole TUDO no campo Cookie │ └─ x-csrf-token: a1b2c3… ← cole no campo x-csrf-token └─ Payload / Request └─ { "tag": "carecavip", … } ← etiqueta

Dicas: Cookie e CSRF têm que ser da mesma requisição. Não copie só um pedaço do Cookie. Se aparecer login/302, a sessão morreu — gere de novo. Não compartilhe esses valores (são login da conta).
